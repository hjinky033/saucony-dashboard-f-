## 🚀 배포 방법

### 방법 1: GitHub 웹 UI
1. https://github.com/hjinky033/saucony-dashboard-f 접속
2. `data.json` 파일 클릭 → Edit 아이콘
3. 새 `data.json` 내용 붙여넣기
4. "Commit changes" 클릭
5. `images.json` 파일도 동일하게 교체
6. `index.html` 교체 (반응형 CSS 포함)
7. 커밋 메시지: `v18: 최신 데이터 + 반응형 UI (813 레코드, 67 이미지)`

### 방법 2: Git CLI
```bash
git clone https://github.com/hjinky033/saucony-dashboard-f.git
cd saucony-dashboard-f
cp path/to/data.json .
cp path/to/images.json .
cp path/to/index.html .
cp path/to/dashboard.js .
git add .
git commit -m "v18: 최신 데이터 + 반응형 UI"
git push origin main
```
